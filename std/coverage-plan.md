## Execution protocol

1. Expand each curriculum chapter cluster into source-anchored definitions,
   constructions, core results, required methods and actual downstream uses.
   Audit existing declarations before labeling an item missing or covered.
2. Follow the curriculum map's dependency waves. Secondary geometry, equations,
   continuous analysis, statistics and the absent source lanes remain explicit
   work; existing algebra and analysis modules do not stand in for them.
3. Choose a bounded mathematical slice and a real consumer before proof work.
   Deliver definitions, actual constructions and the main result together;
   do not substitute a collection of convenient isolated lemmas.
4. Use one persistent Session per context, one statement at a time. Retain the
   process after ordinary failure and journal accepted source and rejection
   evidence under `.verification/`. Materialize coherent accepted batches only.
5. At each batch, run a clean strict file and actual caller; require exit 0,
   Normal `kind=run`, `run_result=success`, empty errors,
   `session_terminated=false`, `termination=null`. Verify false claims and
   missing premises fail at the intended final statement.
6. Update the owning README and mathematical manual. Record an exact blocker
   here when it prevents a main result, then continue independent mathematics.
7. Mark a chapter covered only against the curriculum map's acceptance contract.
   A native operation, declared predicate, source-only gate or easy special
   case cannot by itself close a textbook chapter. Remove disposable artifacts
   at the requested cleanup boundary; preserve existing unrelated work.
