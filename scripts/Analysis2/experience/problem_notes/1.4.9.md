# Lemma 1.4.9: sharing one late subsequence term

The decisive construction is to use
`finite_set_max(union({N0}, {N1}))` as the subsequence index. Positive-index
induction supplies `phi(t) >= t`, which lets the Cauchy estimate compare any
original tail term with `u(phi(t))`.

As with Lemma 1.4.3, `$fn_eq` must first be turned into ordinary function
equality, then applied at `t`, before the anonymous subsequence function can
be unfolded. Two strict-or-weak `epsilon/3` bounds are enough for the final
strict epsilon estimate. The full proof passed in a persistent release `try:`
session before the Chapter 1 `-f` checkpoint.
