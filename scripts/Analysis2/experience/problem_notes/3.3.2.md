# Corollary 3.3.2 war story

The earlier attempt unfolded the quantified hypothesis
`is_metric_continuous(..., family(n))` inside a nested `forall` and produced
an `ExecStmtError`. The working pattern was smaller: call
`chap2::metric_continuous_implies_continuous_at` directly for the current
`n` and `x0`, collect the pointwise family-continuity fact, then apply Theorem
3.3.1 and fold the outer `forall` into global continuity.
