# Lemma 1.1.1: make the distance formula reusable

The metric-tail proof itself is symmetric: keep the same tail witness in both
directions. Litex does not automatically unfold an exported `have fn` at this
later proof site, so the checked route first introduces the small reusable
formula theorem `real_distance_eq_abs`.

The remaining normalization needs three explicit facts: `abs(t) >= 0`,
`abs(abs(t)-0) = abs(abs(t))`, and `abs(abs(t)) = abs(t)`. This pattern is
useful whenever a nonnegative real-valued construction is measured again with
the real distance. The final Chapter 1 release `-f` gate passed.
