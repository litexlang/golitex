# Proposition 1.1.19: discrete convergence

The natural proof was already exactly the Litex proof. The useful pattern is
to isolate the pointwise tail fact in a `claim` before constructing the
eventual witness: control commands such as `by def` belong in that claim, then
the witness body can use the instantiated pointwise result directly.

For the forward direction, `1 / 2 $in R_pos` makes the zero-or-one discrete
distance law decisive. For the reverse direction, unfold eventual equality to
obtain a tail index, prove that its distance is zero, and use the same index
for every epsilon. Both proofs verified as literal outermost `try:` blocks in
a persistent release session.
