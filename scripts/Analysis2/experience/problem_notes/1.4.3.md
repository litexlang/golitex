# Lemma 1.4.3: transporting a convergence tail to a subsequence

The useful proof spine is short: induct to obtain `phi(n) >= n`, use the
original tail bound at `phi(n)`, and rewrite the subsequence value.

Litex needs the rewrite in three explicit stages: first derive ordinary
function equality from `$fn_eq`, then apply that equality at `n`, then unfold
the anonymous function application. Writing only `v(n) = u(phi(n))` did not
verify. The final proof was checked in a persistent release `try:` session
before the Chapter 1 `-f` checkpoint.
