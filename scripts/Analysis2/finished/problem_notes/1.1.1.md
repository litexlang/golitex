# Lemma 1.1.1

source: Tao, *Analysis II*, fourth edition, Lemma 1.1.1.

problem: A real sequence converges to `a` exactly when its real distance from
`a` converges to zero.

proof_idea: In either direction, retain the same epsilon-tail index. The
distance from `abs(u(n)-a)` to zero is again `abs(u(n)-a)` after explicitly
using nonnegativity and simplifying `abs(abs(t)-0)`.
