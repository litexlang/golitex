# Finite tail events and inequalities

The supplied FiniteProbabilitySpace owns its actual finite nonempty carrier,
normalization, nonnegativity and binary disjoint additivity. X is actual data:
a complete real-valued function on that carrier. A is an event value, and a is a
real threshold. No two-point assumption belongs to the generic mathematics.

The forward derivation is:

1. Existing singleton normalization and finite sums define finite expectation.
2. The carrier partitions into A and its complement. Nonnegative X and atom
   weights make the complement sum nonnegative. Thus the event weighted subsum
   is at most EX.
3. X>=a on A gives aP(A)<=EX by finite sum comparison/scaling. Positive a permits
   division and proves the Markov event bound.
4. The centered square is nonnegative. abs(X-EX)>=a gives its value at least a^2
   on A. Apply Markov to this square; its expectation is the existing variance.
   This proves Chebyshev without nonnegativity of X or positive variance.
5. The source tail functions return the exact native set-builder subsets of
   the actual carrier. Membership supplies each event premise, yielding the
   tail versions without a new mathematical axiom or search rule.

scalar values or native objects. Their template parameters are Omega and space;
the ordinary arguments are X and a. Constructors allow all real thresholds;
only the four inequality theorem interfaces require a in R+. The event versions
