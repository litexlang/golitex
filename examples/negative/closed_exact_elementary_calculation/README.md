# Closed exact elementary calculation: negative boundaries

Run each `.lit` independently with `target/release/litex -strict -f <file>`.
Require process exit 1 and JSON `success: false`, with no parse/session error.
These cases retain wrong results, integer domains, principal roots, zero
divisors, logarithm domains, unsupported irrational logarithms, and overflow.
No modular-power or finite-set feature is added by this task.
