# Mathematical dependency graph acceptance

The chosen reader contract exposes mathematical content: definitions, reusable
theorems and accepted facts. `by thm` and `by def` are source details of edges.
Search and well-definedness operations are not nodes. Inferred and local facts
are folded by default; edges express recorded dependencies rather than time.

## Tracer and implementation

Before this change, the current CLI rejected `-graph` as an invalid launch
option (exit 2). The durable tracer is `math_dependencies.lit`. Its two
`by thm only_natural(...)` statements now produce one shared theorem node and
two `theorem_instance` edges to the accepted facts `1 >= 0` and `2 >= 0`.
`have x R = 2` and `x > 0` also retain the actual stored equality dependency.

Run and render from the repository root:

```sh
target/release/litex -graph -strict -lang zh -f examples/stmt_nodes/graph/math_dependencies.lit > graph.json
python3 src/graph/render_html.py graph.json graph.html
```

The paired JSON and standalone HTML were generated by the release binary
with SHA-256 `b0c11e0be8a1d41e81c6c3c6a373621ae76e44aadc546e27fbc6954b180392b6`.
The exporter observes existing execution results before the existing file
finish/abort boundary. It does not rerun search, mutate verifier environments
or change AST/Runtime/ModuleManager shapes. Successful theorem results now
retain their typed `TheoremCall` subject, preserving qualified ownership and
arguments; Normal output still derives the same short display name.

## Limits and retained evidence

Run-local IDs and dependency groups are not a stable external ABI or minimal
atomic proofs. `history_available` records captured dependency/source history,
not an independently replayable certificate. Cache-loaded interfaces can lack
their original dependency history. Earlier successes in an aborted file are
historical, with `published: false`. A successful graph may depend on trust;
origins remain visible rather than being presented as trust-free results.

The shipped viewer is offline and supports English/Chinese UI. Other graph
locales use its English UI while keeping source mathematics. No browser
screenshot or successful browser interaction is claimed for this acceptance.
