# Mathematical organization

Unique finite basis length licenses a natural dimension value only on a
proven finite-dimensional space. Basis comparison supplies that uniqueness;
this export adds source selection and usable bounds rather than a new axiom.
The value theorem settings expose the same domain before any partial call.

A vector outside the current span extends an independent list. The known
basis length bounds the number of possible extensions. Induction on the
remaining deficit constructs a basis with the original list as an ordered
prefix. Range inclusion alone would not express this requirement.

The plane example starts from the genuine nonempty independent prefix (e1),
obtains a length-2 basis and proves that its first entry is still e1. Its
second vector remains existential. Unique coordinates for the resulting basis
check downstream usability without pretending that those coordinates are fixed.
Real/zero spaces exercise dimensions 1/0 and empty prefixes.
