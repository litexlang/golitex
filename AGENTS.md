taking task actions. If that skill is not installed, load
`golitex-skill-update.1jQpTX/golitex-repository-policy/SKILL.md` directly.
Read its bundled repository policy completely and apply it alongside every
task-specific Litex skill.

The policy skill is the canonical source for repository workflow, Litex
verification, textbook artifact boundaries, translation records, Rust
conventions, documentation, and testing requirements. Do not duplicate those
rules here.

User instructions take precedence over the policy skill. The repository policy
takes precedence over generic or older workflow advice in another Litex skill.
