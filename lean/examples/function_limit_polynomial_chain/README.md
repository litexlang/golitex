# A polynomial limit through generated certificates

This example proves

\[
\lim_{x\to 2}(x^2+1)(x-2)=0.
\]

The [Litex source](statement.lit) defines seven real functions and builds the
limit from existing rules:

| Function | Limit at 2 | Recorded rule |
| --- | --- | --- |
| `x` | 2 | Identity |
| `x²` | 4 | Natural power |
| `1`, `2` | 1, 2 | Constant |
| `x²+1` | 5 | Addition |
| `x−2` | 0 | Subtraction |
| `(x²+1)(x−2)` | 0 | Multiplication |

It first establishes real-domain accumulation. Each later call retains the
complete function signatures, equal-domain proofs, earlier limit citations and
pointwise equation required by that rule. The final fact and selector equality
reuse the resulting product limit.

The four files have separate roles:

- [statement.lit](statement.lit) owns the mathematical proof.
- [statement.lean](statement.lean) is generated by the compiler. Its final limit
  fact is `h_47854`; the product function is `_object_i13`.
- [Adapter.lean](Adapter.lean) interprets that exact function graph in the numeric
  model and converts the generated epsilon estimate into Mathlib `Tendsto`.
- [Final.lean](Final.lean) exports an ordinary Lean theorem:

```lean
theorem polynomialProductLimit :
    Tendsto (fun x : ℝ => (x^2+1)*(x-2)) (𝓝[≠] 2) (𝓝 0) := by
  exact Adapter.polynomialChainLimit
```

A Mathlib client imports `examples.function_limit_polynomial_chain.Final` once
`Litex.lean` and the example modules are on its Lean library path. Its theorem
statement contains only standard real numbers, functions, filters and limits.

Regenerate the proof from the repository root:

```sh
target/debug/litex -strict -lean \
  -f lean/examples/function_limit_polynomial_chain/statement.lit \
  > lean/examples/function_limit_polynomial_chain/statement.lean
```

The 17-statement source generates 187,428 bytes (about 187 KB) of Lean. Strict source checking,
byte-identical regeneration and Lean 4.31.0 / Mathlib 4.31.0 checks cover the
generated proof, Adapter and Final. The native exports depend only on
`propext`, `Classical.choice` and `Quot.sound`. Removing the generated proof
citation makes the Adapter fail.

See the [compiler design](../../../src/compile_to_lean/README.md) for the typed
result, WD and citation mechanisms used here.
