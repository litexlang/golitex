# 数学分支样章导读

这组样章围绕一个共同问题展开：怎样从熟悉的例子出发，建立概念、证明结论，再把结论用于下一步数学？七篇正文沿用现有公开讲义的英文。每篇都可以独立阅读，包含核心论证、具体例子、练习与参考答案。

| 样章 | 阅读时抓住的问题 | 主要数学收获 |
| --- | --- | --- |
| [线性代数：向量与唯一坐标](01-linear-algebra.md) | 为什么两个方向既要能够张成，又要线性无关？ | 理解基如何同时保证表示存在和表示唯一。 |
| [抽象代数：同态丢失了什么](02-abstract-algebra.md) | 为什么只看映到单位元的元素，就能判断单射？ | 从消去律出发，证明平凡核与单射等价。 |
| [拓扑：同一个函数的不同连续性](03-topology.md) | 恒等函数为什么可能只有一个方向连续？ | 区分集合上的双射和拓扑空间之间的同胚，并用原像证明复合连续。 |
| [分析：数列极限为什么唯一](04-analysis.md) | 两个误差要求给出的起点不同，如何同时使用？ | 用共同尾部和三角不等式证明唯一性，再定义有条件的极限值选取函数。 |
| [数论：不定方程与贝祖见证](05-number-theory.md) | 什么条件决定整数方程是否有解？ | 在给定 gcd 与贝祖证书后，证明整除判据的两个方向，并构造具体整数解。 |
| [概率：期望与条件概率](06-probability.md) | 加权平均和得到新证据分别改变了什么？ | 推导两点分布的期望线性性，并在一致的联合概率数据上使用贝叶斯公式。 |
| [几何：构造一个等边三角形](07-geometry.md) | 一个坐标公式怎样成为几何存在性证明？ | 构造等边顶点、证明距离恒等式，再完整讲解 IMO 1966 第六题的四分之一面积界。 |

第一次阅读可以从线代或数论开始。它们的计算具体，也最容易看见“找到一个对象”和“证明对象具有所需性质”的区别。随后读抽象代数与拓扑，观察同一套接口怎样支持一般定理和具体反例。分析篇适合练习量词与见证的依赖关系；概率、几何则展示这些方法怎样进入应用。

正文中的短代码块分两类：独立例子含有所需定义，可以单独运行；标注为源码摘录的代码依赖完整源文件中的前置定义。每篇都链接到完整源码，不能把一个上下文摘录误当成独立程序。练习答案给出普通数学论证，除非另有明确说明，不把它们计作新增的形式化成果。

这一批聚焦于各分支中可以完整讲清楚的主题。数论篇的 gcd 是携带贝祖数据的证书，不宣称已经证明任意整数对的贝祖定理；概率篇使用有限分布，几何篇使用实坐标平面。分析篇不依赖 Tao 长篇中另行声明的用户公理，代数篇也不借用仍有证明债的 Sylow 迁移稿。
