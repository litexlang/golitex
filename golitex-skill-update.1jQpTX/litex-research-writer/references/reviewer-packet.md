# Reviewer Packet

A serious reviewer should see these within 10 minutes:

1. The problem matters.
2. Litex has a different design point.
3. The artifact runs.
4. The risks are known.
5. Funding or support turns it into a public good.

Recommended packet:

- Executive summary: one page.
- Demo: one full example with verifier output.
- Benchmark table: attempted, expressible, checkable, blocked.
- Blocker taxonomy: stdlib, infer rule, kernel, syntax, diagnostics, formulation.
- Soundness/scope note.
- 6-10 page technical proposal.
- Narrow external feedback quotes or notes.
