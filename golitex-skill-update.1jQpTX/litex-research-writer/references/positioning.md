# Litex Positioning

## For Proof Assistant Researchers

Litex is a complementary interface experiment: fact-oriented, readable, local proof repair, explicit proof debt, and benchmarkable failure categories.

Avoid claiming superiority over Lean. Instead ask whether a smaller checked-math interface can make some classes of formal data cheaper to produce.

## For AI-for-Math Researchers

Emphasize machine-checkable feedback, repair traces, benchmark slices, and formal data production.

Good claim: Litex exposes local mathematical failures that agents can repair.
Bad claim: Litex solves autoformalization.

## For Funders

Emphasize infrastructure, public corpus, benchmark, web editor, documentation, and soundness/scope work.

The funding story is that money turns a working artifact into reusable public infrastructure.

## For Educators

Emphasize readable checked mathematics, student proof practice, explicit facts, and fast feedback.
